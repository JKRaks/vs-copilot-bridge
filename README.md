# Copilot Gateway

把多个 Endpoint 接入同一个本地地址，在 Github Copilot for Visual Studio 中通过模型名称选择要使用的服务。

为解决 Visual Studio 版 GitHub Copilot 的相关实现闭源，无法像其他客户端一样通过 CCSwitch 等工具直接切换服务。因此，本项目利用 Copilot 提供的自定义 OpenAI / Ollama 终结点，将多个服务商的地址、API Key 和模型名称统一管理，方便在 Visual Studio 内选择使用。

## 开始使用

需要安装 Node.js 20 或更新版本。

1. 双击 `start.cmd`。
2. 在“提供商”页填写服务地址和 API Key。
3. 在“模型映射”页设置显示名称、提供商和实际模型名称。
4. 回到首页，用上下键选择 OpenAI 或 Ollama，按 Enter 勾选，再按 S 启动。

服务地址按提供商文档填写；需要 `/v1` 时请自行加上。若填写了 Key 环境变量，优先使用环境变量中的值。

## 按键操作

| 操作 | 按键 |
|---|---|
| 切换页面 | Tab / 左右键 |
| 选择项目 | 上下键 |
| 勾选入口、编辑字段 | Enter |
| 新增 / 删除 | A / D |
| 启用 / 禁用模型 | 模型映射页按 E |
| 保存配置 / 放弃修改 | Ctrl+S / Esc |
| 启动 / 停止代理 | 首页按 S |
| 退出并停止代理 | Q / Ctrl+C |

编辑字段时输入新值，按 Enter 确认，再按 Ctrl+S 保存。密钥会隐藏显示。

模型映射支持运行时修改：名称、路由、能力、启用状态和描述备注保存后约半秒生效，无需停止代理。直接修改配置文件也会自动加载；格式错误时继续使用原配置。提供商、密钥、端口等其他设置仍需停止后修改并重新启动。

禁用模型后，它会从可选列表中隐藏，新的调用会被拒绝；已经开始的请求不受影响。备注仅用于说明模型，不会加入发给 AI 的内容。VS 若仍显示旧列表，请刷新模型列表或重新打开聊天。

界面中绿色表示运行、完成或启用，黄色表示正在处理，灰色表示停止或禁用，红色表示失败。

## 在 VS 中连接

在自定义模型提供商中任选一种，确保首页已勾选并启动对应入口：

| 配置 | OpenAI | Ollama |
|---|---|---|
| 终结点 URL | `http://127.0.0.1:8788/v1` | `http://127.0.0.1:8788` |
| API Key | `local-gateway` | 不需要 |

以上为默认值，修改端口或网关 Key 后请同步更新 VS。随后选择配置好的模型；更换终结点后，建议重启 VS 并新建聊天。

## 使用说明

- 两种入口均支持聊天、工具调用和图片输入，实际能力取决于所选模型。请在模型配置中按实际情况勾选“工具调用”和“视觉输入”。
- Ollama 入口用于连接这些在线服务，不提供其他功能。
- 日志保存在 `logs` 文件夹，每个文件最多 1 MiB，保留 3 个备份，旧记录自动清理。
- 不要公开包含密钥的 `config/config.json`。调试日志可能包含对话和代码，分享前请检查。
